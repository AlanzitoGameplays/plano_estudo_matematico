# Plano de Estudo Matemático 3.1

Repositório de trabalho editorial e técnico do Plano de Estudo Matemático 3.1.

## Estrutura

- `regras/` — normas canônicas de HTML/CSS.
- `referencias/` — materiais gerais de referência.
- `topico-1.1-logica/` — materiais do Tópico 1.1 — Lógica Matemática.
- `ferramentas/` — scripts e utilitários de geração.
- `VERSOES.md` — registro de versões congeladas.

## Fluxo

1. Conteúdo mestre aprovado em Markdown.
2. Construção/revisão de HTML e CSS em branch própria.
3. Geração local do PDF no Chrome/Windows.
4. Preflight.
5. Patches cirúrgicos.
6. Merge em `main` e congelamento.
